# Observability workspace convention

The checkout team uses one empty LaunchDarkly observability dashboard named **Checkout Ops Review 1011** as the workspace for the current authorization investigation. If that dashboard is absent during an active investigation, create it before completing the incident summary and include its URL in the handoff. Leave it empty unless the operator separately asks for graphs.

Do not create or modify flags, alerts, integrations, repositories, environments, or access controls.
